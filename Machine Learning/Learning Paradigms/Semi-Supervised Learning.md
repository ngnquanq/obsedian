# Semi-Supervised Learning

Semi-supervised learning is useful when labels are expensive but unlabeled data is cheap. It keeps the supervised goal of predicting $Y$ from $X$, but tries to use the unlabeled distribution of $X$ to learn a better decision rule.

---

## Why Semi-Supervised Learning Exists

Imagine a fraud team with 5,000 confirmed labels and 50 million unlabeled transactions. Training only on the labeled set may ignore most of the data distribution, but manually labeling everything is unrealistic.

**Semi-supervised learning solves this by combining a small labeled dataset with a much larger unlabeled dataset from the same problem population.**

```text
Small labeled set: (X, Y)
Large unlabeled set: X
        |
        v
Learn structure from all X
        |
        v
Improve prediction of Y
```

---

## Core Framing

Semi-supervised learning still has a supervised objective:

$$
\hat{f}(X) \approx E[Y \mid X]
$$

The difference is that unlabeled data helps shape the function. This only helps when the unlabeled examples reveal structure that is relevant to the label.

---

## When It Is Suitable

Use semi-supervised learning when:

- labels are costly, delayed, sensitive, or manually reviewed;
- unlabeled examples come from the same population as future prediction cases;
- the labeled set is too small to cover the feature space;
- similar examples are likely to share labels;
- evaluation labels are held out and not generated by the model itself.

Avoid it when the unlabeled data comes from a different population, labels are noisy, or model-generated pseudo-labels would reinforce existing errors.

## Evaluation

See [[Machine Learning/Learning Paradigms/Semi-Supervised Evaluation|Semi-Supervised Evaluation]] for evaluation design. The short rule: compare against a supervised baseline trained only on labeled data, then test on a clean labeled holdout that was not used for pseudo-labeling.

---

## Interview Reference

- Semi-supervised learning combines labeled and unlabeled data.
- The goal remains supervised prediction.
- It works best when unlabeled data reveals label-relevant structure.
- The main risk is confirmation bias from wrong pseudo-labels.
- Always compare with a labeled-only baseline.
