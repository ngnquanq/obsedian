Write an sql query to return all valid products withouth any active contracts

select p.skp_product, p.code_product, p.name_product, p.value
from 
    product p left join contract c on p.skp_product=c.skp_product 
where 
    p.value='Valid'
Group by p.skp_product, p.code_product, p.name_product, p.value
Having count(case when c.contract_status='Active' then 1 end) = 0; ^NWVuAtrH

Write an SQL query to show the number of active contracts,
 number of closed contracts and total AMT_BALANCE for each NAME_PRODUCT of valid product
 sorted by descending number of active contracts.

select 
    p.name_product, 
    sum(case when c.contract_status='Active' then 1 else 0 end) as number_active_contracts,
    sum(case when c.contract_status='Closed' then 1 else 0 end) as number_closed_contracts,
    sum(c.amt_balance) as total_amount_balance
from
    contract c left join product p on c.skp_product=p.skp_product
where 
    p.value='Valid'
group by p.name_product
order by number_active_contracts DESC ^nF8ZXPtW
